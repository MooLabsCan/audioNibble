Which audio format should I use?

WAV
Best for: Professional audio, music production, archival

Uncompressed, lossless quality. No audio data is lost. Use when you need the highest fidelity — studio recording, mastering, sound design, or as a source file for further editing. Large file sizes.

Music ProductionFilm / VideoArchivalSound Design
MP3
Best for: Sharing, websites, universal compatibility

The most widely supported format. Good compression with acceptable quality at 192+ kbps. Use for music distribution, podcasts, website audio, or when file size matters and you need maximum device compatibility.

PodcastsMusic SharingWebsitesMobile Apps
OGG
Best for: Games, web apps, open-source projects

Open, royalty-free format with better compression than MP3 at similar quality. The go-to choice for game engines (Unity, Godot, etc.), HTML5 games, and quick sound effects. Smaller files than MP3 at equal quality.

Game SFXHTML5 GamesUnity / GodotWeb Apps
WEBM
Best for: Web video, streaming, modern browsers

Optimized for web delivery using the Opus codec. Excellent compression and quality. Ideal for pairing with video content, web streaming, or modern progressive web apps. Not supported in all native apps.
